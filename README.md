## 🛠️ तकनीकी संरचना (Technology Stack)

### Frontend
* **React 18** (Vite 5 बिल्ड सिस्टम)
* **Tailwind CSS** (पारंपरिक भारतीय सांस्कृतिक रंग पैलेट: गहरा केसरिया, स्वर्ण, रोली/सिंदूरी लाल, चंदन/क्रीम)
* **Framer Motion** (चिकने और अर्थपूर्ण एनिमेशन्स)
* **Lucide React** (सुंदर और आधुनिक आइकन्स)
* **React Router DOM 6** (क्लाइंट-साइड नेविगेशन)
* **React Helmet Async** (सटीक SEO मेटाडेटा एवं OpenGraph)
* **द्विभाषी प्रणाली (Bilingual System)**: हिन्दी (प्राथमिक/डिफ़ॉल्ट) एवं English (एक-क्लिक स्विचर के साथ)

### Backend
* **Node.js (v20+ / v24)** & **Express.js** (REST API आर्किटेक्चर)
* **SQLite (via better-sqlite3)** (उच्च प्रदर्शन, WAL मोड, स्थायी फाइल-आधारित स्टोरेज)
* **JWT (JSON Web Token)** (प्रशासक प्रमाणीकरण)
* **bcryptjs** (सुरक्षित पासवर्ड हैशिंग)
* **Multer** (छवि अपलोड एवं 10MB सुरक्षा सीमा)
* **CORS & Morgan** (सुरक्षित क्रॉस-ओरिजिन एवं लॉगिंग)

## 🚀 स्थापना एवं चालन (Installation & Local Setup)

### 1. पूर्वापेक्षाएँ
* Node.js v18 या उच्चतर
* pnpm (अनुशंसित) अथवा npm

### 2. निर्भरताएँ संस्थापित करें (Install Dependencies)
```bash
# Backend निर्भरताएँ
cd backend
pnpm install

# Frontend निर्भरताएँ
cd ../frontend
pnpm install
```

### 3. डेटाबेस इनिशियलाइज़ एवं सीड करें (Seed Database)
```bash
node backend/src/database/seed.js
```
*यह कमांड सभी 66 कार्यकारिणी सदस्यों, 28 आधिकारिक सेटिंग्स, 2026 छठ महापर्व कार्यक्रम, प्रारंभिक गैलरी एवं व्यवस्थापक खाता को SQLite डेटाबेस में स्वतः भर देगा।*

### 4. डेवलपमेंट मोड में चलाएं (Run in Development)
```bash
# टर्मिनल 1: Backend API (पोर्ट 5000)
cd backend
pnpm run dev

# टर्मिनल 2: Frontend Vite Server (पोर्ट 3000)
cd frontend
pnpm run dev
```
ब्राउज़र में खोलें: `http://localhost:3000`

### 5. प्रोडक्शन बिल्ड एवं रन (Unified Single Server Production Run)
```bash
# Frontend का प्रोडक्शन बंडल बनाएं
cd frontend
pnpm run build

# Backend सर्वर प्रारंभ करें (यह API तथा बिल्ट Frontend दोनों को एक साथ होस्ट करता है)
cd ../backend
pnpm start
```
वेबसाइट `http://localhost:5000` पर लाइव उपलब्ध होगी।

## 🌐 डिप्लॉयमेंट निर्देश (Deployment Guide)

### विकल्प A: एकीकृत होस्टिंग (Render / Railway / VPS / Docker) — अनुशंसित
1. रिपॉजिटरी को गिटहब पर पुश करें।
2. Render / Railway पर **Web Service** बनाएं।
3. **Build Command**: `pnpm --prefix frontend install && pnpm --prefix frontend run build && pnpm --prefix backend install`
4. **Start Command**: `node backend/src/server.js`
5. **Persistent Disk (स्थायी स्टोरेज)**:
   * SQLite डेटाबेस और अपलोड की गई तस्वीरों को सुरक्षित रखने के लिए बैकएंड होस्ट पर `/var/data` माउंट करें।
   * पर्यावरण चर सेट करें: `DB_PATH=/var/data/samiti.sqlite`

### विकल्प B: अलग-अलग होस्टिंग (Vercel + Render)
1. **Frontend (Vercel)**:
   * Root Directory: `frontend`
   * Build Command: `pnpm run build`
   * Output Directory: `dist`
   * Environment Variable: `VITE_API_URL=https://your-backend.onrender.com`
2. **Backend (Render / Railway)**:
   * Root Directory: `backend`
   * Persistent Volume माउंट करें ताकि डेटा कभी नष्ट न हो।
